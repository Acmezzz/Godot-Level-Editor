# 第三轮复审修复清单

基线 `cccfd3e`。按发布影响和依赖拆批，逐项记录完成状态。项目格式沿用 v7。

## 发布阻断

- [x] A1 暂存键误作内容 ID。会话快照保留真实 `fn_id/cid`，非法目标写前中止，冻结地图仍依赖的暂存不得丢弃。生产复合键回归及表单、地图文件脚本检查通过。
- [x] A2 暂存沿用创建意图，地图读取返回同源摘要，冻结计划拒绝非法目标并复验缺失、现有摘要和不可读状态。检查与文件系统替换之间仍有平台竞态窗口。清单外部覆盖确认见 B2。
- [x] A3 跨图清理重新扫描正式地图，目录或文件读失败即中止。每张目标图绑定同源摘要，完整及部分成功均由逐图收据触发当前画布重载。回归覆盖部分写入收据，画布重载经过脚本检查。

## 数据完整性与编辑正确性

- [x] B1 常规提交互斥，冻结地图和清单，确认后校验文档代次和修订。试玩校验提交收据或未改地图的正式基线。
- [x] B2 清单使用解析正文的摘要作为加载基线。覆盖确认绑定到当时看到的磁盘版本，并在写前复验项目身份和序列化工作副本（`app.gd`、`manifest.gd`）。
- [x] B3 已落盘改名将新文件正文与旧文件删除写入同一计划，保留部分成功提示。未落盘改名先保存清单并消费已写内容收据。整图复制先校验地图，再提交内容与地图。
- [x] B4 待处理日志在写入前记录操作、来源和可预计算的结果摘要。回归覆盖文件写入成功但未回填进度时的重启判定，冲突结果保留先前已写目标。
- [x] B5 打开、新建、草稿和历史恢复在载入成功后清理旧文档暂存。草稿拒绝撞码及身份不符的同名文件，清单落盘后移除临时发码授权。
- [x] B6 连续、布尔、颜色、单选和多选控件写失败后可重试。显示名、库复用和共享改绑复验绑定身份，主表单与步骤字段复验配对地图。
- [x] B7 批改复验预览目标、绑定、声明和逐条旧值。关系图复验声明、引用值与步骤快照，正式内容写入绑定同源摘要。配对引用确认后复验实例和属性。批改与关系图过期写入回归通过，配对引用经过脚本检查。
- [x] B8 整图、实例及区域复制按功能 ID 和内容 ID 定位源内容。剪贴板保留复制时的源图身份与暂存载荷，暂存优先于正式文件。同名 ID 和暂存优先级回归通过。
- [x] B9 删除前扫描正式地图、画布、内容与草稿，计入瓦片和声明的嵌套引用。不可读时阻断，确认后复验。删除与停用在清单落盘后发布。瓦片、嵌套引用和损坏地图回归通过。
- [x] B10 自动重链要求旧条目和新路径双向唯一，原位变更刷新指纹。手动确认复验候选归属、文件指纹和类型，发号避开已占用身份。争用与过期候选回归通过。
- [x] B11 预览与裁剪使用同一拓扑列数，摆放物仍按连续基坐标判界。纯扩图保留已有数据。应用前和确认后复验文档身份及修订；三角边界回归通过。
- [x] B12 保留未解析实例的身份码、扩展变换和属性。未解析瓦片按层与格保存，参与笔刷、区域操作与撤销。擦除、撤销和重做回归通过。
- [x] B13 碰撞层统一使用格笔刷和区域框选，预览与剪贴板遵循同一分流。瓦片替换在预览和写入时检查实际切片，写前复验源格。相关脚本检查与自动化套件通过。
- [x] B14 画面一致档遵循图层和实例显隐、层栈与实例排序段。预览和导出共用格形、切片变换与碰撞几何。PNG 实例使用格内色标，预览使用缩略图。两者省略视差与瓦片逐格 Y 排序，内容预览使用普通混合。

## 性能、维护与诊断

- [x] C1 地图索引接入项目写入版本，功能执行码按声明指纹缓存反向索引。关系图按目标功能复用目录结果。
- [x] C2 笔刷更新受影响的三角瓦片块，视口使用保守格窗口。碰撞和小选区按需查询格子，内容预览分别缓存瓦片和实例排序。
- [x] C3 PNG 限制像素、边长、条目数和估算绘制工作量。时间轴按视口重绘，重叠统计不用枚举所有配对。
- [x] C4 校验地图数值有限性和整数范围。瓦片坐标查重独立于资产校验。格图和格边复核格式、范围及相邻关系。
- [x] C5 正式地图、冻结地图摘要和整图撤销共用地图编码。差量与整图提取共用瓦片行。地图和恢复文件共用原子写入。
- [x] C6 逐目标收据保留状态和错误。实际摘要与写前日志一致时跳过进度回填，重启仍按磁盘状态判定。
- [x] C7 Prefab 尺寸沿挂载链合成变换，跳过禁用形状。旧试玩偏好落盘后移除旧图名键，保留显式设置。

收尾验证覆盖 25 个改动脚本的解析和 281 项自动化测试，均通过。未跑 GUI 端到端测试。
