# 通用 2D 关卡编辑器收尾审查：BUG 与优化

审查日期：2026-11-25。源码基线：`d110a3d`，与本轮工作区已跟踪的 `src/` 脚本一致。仅检查 `src/` 下的编辑器实现；没有审核游戏工程、外部工具或仓库测试。

**当前确认 15 项 BUG：8 项 P1、6 项 P2、1 项 P3。本轮新增 F14–F16，三项均已复现。** 这份清单记录了当前有明确触发条件的问题，不能证明已经找出全部 BUG。已复现的只限文中标明的步骤，其余为源码确认；每项的验收步骤留待修复后集中执行。旧版 F09 是共享绘制的使用边界，已移出清单，其他编号保留。

## BUG

### F01 · P1：保存和另存失败可留下部分正式文件

[普通保存](../../src/ui/map_file.gd#L824) 先写清单和暂存内容，再进入[地图确认与写入](../../src/ui/map_file.gd#L894)。有新绑定内容的地图被外部改过时，取消覆盖仍可能留下已经写出的内容。[另存与改名计划](../../src/project/document_commit.gd#L38) 也会边检查边写：**已复现**第二条内容目标事先被占用时，第一条已写，地图没写。已落盘地图改名时先写新图再删旧图；删旧图失败会留下两个同码文件，同名重试又会被拒绝。

**修复：** 复用现有发布计划，先收集载荷，确认所有已知冲突并校验，再按清单、内容、地图的顺序写。运行中遇到 I/O 失败，保留计划并按摘要识别已完成写入，让同一次操作可以续跑；改名续跑只删仍符合原摘要的旧文件。暂存随发布完成消费，独立内容表单的即时写入按原有边界处理。

**验收：** 分别取消地图或清单冲突，比较本次计划目标的写前、写后摘要；第二条内容有预先可知的冲突时第一条应不写；模拟写图失败、删旧文件失败，排除故障后能继续而且只剩一张正式图。

### F02 · P1：粘贴后撤销、保存、重做会丢失复制出来的内容

[实体粘贴](../../src/canvas/selection_ops.gd#L758) 为新实例暂存内容，但[入栈](../../src/canvas/selection_ops.gd#L818) 时未提交内容载荷。普通格区和[跨层区域](../../src/canvas/world_region_move.gd#L244) 粘贴则只留整图快照，快照不含暂存载荷。[保存](../../src/ui/content_form.gd#L787) 在撤销后移除未绑定的内容；重做只能复原实例及绑定。**已复现**暂存被保存清理后，恢复同一绑定并不会恢复暂存；三种粘贴入口的完整按键链为源码确认。

**修复：** 粘贴命令一并保存本次创建的内容载荷，复用[已有实例差量的载荷入口](../../src/core/undo_history.gd#L265)，给区域快照或复合命令补同一语义。重做按 `(功能 ID, 内容 ID)` 恢复未发布暂存；原载荷已经发布时核对摘要，不重复创建。

**验收：** 实体、普通格区和跨层区域分别执行「复制粘贴 → 撤销 → 保存 → 重做 → 再保存 → 重开」，副本绑定能读出独立内容，临时撤销期间没有孤儿文件。

### F03 · P1：裁剪、删除及保存流程可留下悬空的地图引用

[裁剪](../../src/ui/map_resize.gd#L85) 移除越界实例但保留地图出口；[删层](../../src/canvas/layer_ops.gd#L219)、[删实例](../../src/canvas/selection_ops.gd#L849) 和[删格](../../src/map/cell_graph.gd#L320) 也没有共用入边复核。[地图写入校验](../../src/map/map_data_validation.gd#L51) 检查出口结构，不保证目标存在。**已复现**：8×8 地图的出口指向 `(7,1)` 的实例端口，裁成 4×8 后实例被删除，出口仍在，且 `MapStore.write_error()` 返回空串。

**修复：** 编辑命令列出实际移除的目标，复用已有的[空间引用检查](../../src/project/spatial_reference_check.gd#L11)，联合检查当前工作副本与已保存的来向。允许作者重接或断开；正式发布和试玩阻止仍指向已删目标的静态链接，保留可修复草稿。按目标类型分别处理实例、端口、图层、格及格边。

**验收：** 各准备一条本图引用与跨图引用，覆盖删实例、删层、删格和裁剪。来向应能定位；未修时不能静默发布，修复或撤销后可正常保存和试玩。

### F04 · P1：删除保护漏掉通过字段默认值建立的来向

[内容来向](../../src/project/reference_usage.gd#L148) 只在特定字段缺键时取默认，[资源和屏幕来向](../../src/project/reference_usage.gd#L247) 直接跳过未存键；[属性引用遍历](../../src/project/reference_index.gd#L199) 却支持声明默认值。**已复现**：内容文件的 `fields: {}` 通过字段默认值指向屏幕或另一条内容，两个来向查询都返回空。

**修复：** 把「字段值缺键时继承声明」收敛到现有遍历，供删除、图和发布复用；保留显式断线或显式空数组。处理嵌套记录、条件和步骤时一并传入可用的地图上下文；诊断指出来向来自默认值。

**验收：** 同一个默认目标分别测试缺键、显式置空、显式改接及嵌套字段；删除保护与关系图对目标和来向给出一致结果。

### F05 · P1：共享绘制先落盘再绑定；缺图时编辑器静默丢失绘制层

[保存并编辑](../../src/ui/event_layers_dialog.gd#L126) 先[创建并写入地图](../../src/ui/map_file.gd#L38)，随后才保存绑定该图的清单。清单冲突取消或写入失败时，新图已存在，项目没有把它识别成绘制文档。[清单检查](../../src/project/event_layers.gd#L38) 只校验数据形状；[参照加载](../../src/project/reference_index.gd#L14) 直接跳过找不到的图。**已复现**缺失的 `drawingMap` 不报结构问题；取消与写入顺序由源码确认。

**修复：** 先规划新图与清单绑定，复用 F01 的冲突预检；发布时先写图，再发布引用它的清单，写图成功而清单失败时记录可继续的目标。已有绑定指向缺失或重码的图时，在图组面板显示原因和重选入口。

**验收：** 覆盖取消清单冲突、地图写入失败、写图后清单失败与重试；外部删图或引入重复码后，图组显示错误且可以重新绑定。

### F06 · P2：实体粘贴混用了世界像素和图层局部像素

[应用](../../src/app.gd#L598) 传世界鼠标坐标，[复制](../../src/canvas/selection_ops.gd#L654) 用实体局部位置算组内偏移，[粘贴](../../src/canvas/selection_ops.gd#L785) 把两者相加后当目标层局部位置。**已复现**：目标层偏移 `(100,0)`、缩放 `2`，关吸附，光标在世界 `(150,50)`，对象却落到 `(400,100)`。

**修复：** 用[同一对图层变换](../../src/canvas/editor_canvas.gd#L646) 采集世界坐标下的中心和偏移，按光标构造世界落点，再反算到目标层执行局部吸附。要保留各自图层的搬运用跨层入口。

**验收：** 测试单个对象和多选，源层或目标层分别带偏移、缩放，开关吸附各做一次；检查锚点、组内相对位置以及重开后的坐标。

### F07 · P2：另存转换格系会保留已经无效的格边引用

[转换计划](../../src/map/map_convert.gd#L25) 换算实例锚点和出生点；[另存](../../src/ui/map_file.gd#L307) 复用整图克隆，继承本图格边地址，但没有检查新格系是否还有这条边。**已复现**：六边格的 `1,0|0,1` 转正交后仍留在对象字段里，新格系判定两格不相邻，转换计划无告警。瓦片、碰撞原格号保留已在转换预览说明；存根像素的格图多边形也不因此自动失效。

**修复：** 冻结副本前，以目标网格调用[已有格边校验](../../src/project/spatial_reference_check.gd#L97)，覆盖实例属性和随图复制的内容字段。明确列出失效字段；没有唯一对应的地址让作者重选或断开后再发布。

**验收：** 六边转正交时报告不能保留的斜邻边；仍有效的边可继续另存，外部地图上的边不按本图新格系重算。

### F08 · P2：外部图导入换地图码，却保留显式指向原图的地址

[外部 JSON 导入](../../src/ui/map_file.gd#L745) 给地图发新码后直接写入。显式写了原地图码的本图出口或空间引用保留旧码，可能变成悬空地址；目标项目刚好有另一张同码图时也可能误连。[同项目的整图复制](../../src/content/clone_plan.gd#L581) 已经区分自身与外部地图引用。

**修复：** 单图导入复用类型化迁移：只把已知引用中的源图码改成新码，保留本图实例和端口定位；对其余跨图引用、未随图导入的内容，列出需要重接的条目。保持现有单图导入范围，无需先做整项目导入工具。

**验收：** 导入含显式自引用的地图，目标项目先放入一张与旧码相同的图；导入图自己的出口仍应指向自己。另放一条未知外部依赖，界面应指出它需要重接。

### F10 · P2：恢复草稿按裸内容 ID 匹配，未恢复提示随后被盖掉

[恢复暂存](../../src/ui/content_form.gd#L881) 只用 `cid` 找绑定，[正式保存](../../src/ui/content_form.gd#L787) 用 `(功能执行码, cid)`。两个功能目录可以有相同的裸 ID；一份草稿的暂存可在只剩另一功能同 ID 绑定时被误判为已恢复，保存时再被移除。[恢复状态](../../src/ui/map_file.gd#L1055) 无论有没有漏恢复，最后统一覆盖为成功提示。

**修复：** 草稿恢复和保存共用完整的绑定键，报告实际恢复与未恢复的条目，合并为一个状态结果。

**验收：** 两个功能声明下各放一个同 ID 内容；草稿中只保留其中一个功能的绑定，恢复后不可把另一条认领为已恢复，状态栏能看见漏项。

### F11 · P2：自动碰撞落到有偏移或缩放的源层之外

[自动碰撞](../../src/canvas/tool_ops.gd#L297) 禁止独立瓦片格系，却允许共用根格系而有偏移、缩放的源层，随后直接把源格号写到根碰撞层。**已复现**：源瓦片在世界格 `(2,0)`，生成的碰撞在根格 `(0,0)`。替换模式还会按错误的目标集删除原碰撞。

**修复：** 最小修法是在计数和生成入口共用校验：变换与根层不一致时停止并提示。若项目常用整格平移，再支持把源格映射到根层；非对齐时沿用现有自由形状。

**验收：** 单位变换时照常生成；平移、缩放、相机视差下不能写入错位碰撞。拒绝生成时，替换模式也不删除已有数据。

### F12 · P2：同一秒外部改图可能继续使用旧地图码索引

[地图码索引](../../src/map/map_store.gd#L141) 用[图名和秒级 mtime](../../src/map/map_store.gd#L181) 判断能否直接返回旧值。同秒外部改写时，索引连带文件大小的[读缓存](../../src/map/map_store.gd#L29) 都不会触发；地图码、重复码状态和出口候选可能继续显示旧数据。普通地图正式写入另有摘要检查。

**修复：** 编辑器自身写入继续显式失效；项目的外部刷新要核对文件内容变更并同时失效两级缓存，覆盖同秒同长度改写。浏览走批量刷新和按需重建；写入、删除等有副作用的检查读取新状态。

**验收：** 保持文件名、长度和可见 mtime 不变，外部改地图码；刷新后候选应只反映新码，重复码诊断也应同步更新。

### F13 · P3：空历史的新图，第一笔还没松手时 Ctrl+Z 无效

[撤销](../../src/core/undo_history.gd#L65) 在结束当前笔画前检查是否为空栈。空历史时首笔尚未入栈，函数直接返回；已有旧历史时同样操作会结束并撤销当前笔画。

**修复：** 保留文档忙和恢复中的检查，先结束有改动的当前笔画，再检查空栈。

**验收：** 空历史的新图按住左键涂第一笔，按 Ctrl+Z 后当前笔画撤销并能重做；没有改动的手势不产生新历史。

### F14 · P1：字典形式的功能、条件和步骤无法恢复草稿预留字段码

[草稿写出](../../src/project/manifest.gd#L139) 使用规范化后的外层 ID；[恢复](../../src/project/manifest.gd#L219) 却在原始条目的内层读取 `id`。[声明池](../../src/content/declaration_pool.gd#L15) 对字典形式把外层键放在 `pair.id`，不会在 `pair.body` 另补一个。**已复现**：`fnf`、`condf`、`stepf` 三类均能写出字段码，但字典恢复 0 条，等价数组写法恢复 1 条。重开项目若给同一字段补了新码，草稿中按旧码存的值就匹配不到。

**修复：** 用 `pair.id` 定位归属；只回填本次临时补发或仍缺失的字段码，保留已正式写入的码。仍在[装载草稿前](../../src/ui/map_file.gd#L1035) 合并。

**验收：** 数组和字典各测功能、条件、步骤。临时发码后编辑值、写草稿、重启并恢复，字段值仍可编辑和保存；已正式写入的码不会被旧草稿覆盖。

### F15 · P1：原正式图缺地图码时，自动草稿无法恢复

[装载地图](../../src/canvas/editor_canvas.gd#L310) 在工作副本补码并[标脏](../../src/canvas/editor_canvas.gd#L524)。[草稿](../../src/ui/map_file.gd#L949) 带新码与原文件摘要；恢复时正式图尚无此码，[同名回退](../../src/ui/map_file.gd#L973) 又拒绝任何带码草稿。**已复现**：保持原文件字节不变，真实草稿写出后解析目标仍被拒绝；相同摘要的无码草稿可定位。

**修复：** 码查不到时，如果同名正式图仍无码且摘要等于草稿基线，允许定位并在工作副本恢复新码。摘要不合、正式图已换成其他码或草稿码已有歧义时，继续阻止静默覆盖。

**验收：** 打开缺码正式图，等草稿写出后退出而不保存，重开并恢复，再正式保存。原文件在恢复动作期间不变，正式保存后地图码及草稿内容一致。另测同名文件被替换时不误绑定。

### F16 · P1：普通格区框选会剪掉框外的瓦片

[普通框选](../../src/canvas/region_ops.gd#L657) 使用根格矩形；[取瓦片](../../src/canvas/region_ops.gd#L93) 和[剪切](../../src/canvas/region_ops.gd#L407) 用同一矩形直接筛各层局部格号。只检查格系是否相同，没处理共享格系但有变换的图层。**已复现**：图层右移两格，框世界格 `(2,0)`，它对应局部格 `(0,0)`；剪切却留下框内瓦片，删掉世界格 `(4,0)` 的瓦片。普通格区复制、拖动取样也用相同口径。

**修复：** 根格区只用于参与层与根空间对齐的场景；参与层有偏移或缩放时使用已有[跨层区域工具](../../src/canvas/world_region_move.gd)，或停止普通格区操作并提示切换。保留独立瓦片格系原有的单层框选。取样、预览和写入用同一范围。

**验收：** 框内框外分别放瓦片与实例，覆盖位移、缩放和单位变换；核对复制/剪切/拖动处理范围，撤销后复原。框外数据始终不变。

## 优化

下面是源码能定位的成本，还没有性能基准。先修 BUG，再用同一组大地图和多地图工程测量；只有影响正常编辑的项才排进本次收尾。

| 项目 | 可定位的成本 | 最小改法与测量 |
| --- | --- | --- |
| O01 · 地图索引 | [索引查询](../../src/map/map_store.gd#L141) 即使命中缓存，也列目录、对每张地图取 mtime。[主画布](../../src/canvas/editor_canvas.gd#L565) 每秒触发一次。 | 和 F12 一起做：常规浏览读会话索引，本地写入定点失效，外部变化批量刷新。测百图项目中空闲时的目录扫描次数，以及打开地图目标候选的耗时。正式写前继续核对实际文件。 |
| O02 · 大图绘制 | [主画布辅助绘制](../../src/canvas/canvas_draw.gd#L150) 枚举可见层实体，[内容预览](../../src/ui/content_preview.gd#L303) 回绘时扫描根碰撞，瓦片缓存也要按条目筛选。 | 先量平移、笔刷时主画布和内容预览各自耗时；如已成为瓶颈，复用现有分块或视区查询，只处理能进入视区的实体、瓦片和碰撞。测小视窗平移时帧耗时 p95 和每次遍历条目数。 |
| O03 · 大范围编辑历史 | [整图快照](../../src/core/undo_history.gd#L24) 枚举并编码整图，[撤销/重做](../../src/core/undo_history.gd#L65) 还需建对向快照和重建画布。 | 从区域操作开始复用现有差量或记录受影响的格、对象和内容载荷，可和 F02 同改。测「大图、小选区」的复制、撤销、重做耗时，以及连续重复操作的历史内存。少用的整图操作继续保留快照。 |
