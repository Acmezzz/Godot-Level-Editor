- **100 层、单批 10000 格、单批 100 操作、200 行记录，合计 1.8 秒**完成且 validate 全绿。

## 3. 防护探测（故意发坏数据）

| 探测 | 结果 | 判定 |
| --- | --- | --- |
| 非法 blend `"screen"` | **拒绝**，报错精确到 `meta.layers[2].blend` + "must be mix/add/mul" | 防护正确 |

## 4. 发现与优化点（按优先级）

1. **越界瓦片静默接受**（真实，中优先级）：tiles.set 接受任意坐标，数据与渲染都出地图边界
   （截图 logs-exp2/deep-layers.png 可见 40×24 图右缘外的绿色延伸）。建议明确语义：裁剪 / 拒绝 /
   或声明为支持"边缘溢出"的特性——三种都行，就是不要静默。
2. **MCP 草稿编辑后编辑器主画布不自动跟随**（易用性，中）：批量编辑后编辑器窗口仍显示"还没有打开地图"，
   人工复核 AI 制作结果时需要自己找到并打开对应地图。建议：草稿变更时若画布为空，自动打开受影响地图。
3. **负 parallax 无范围校验**（低）：UI 下拉正常使用不会产生负值，MCP/手写数据才会；渲染语义未定义。
   建议 clamp 或校验范围。
4. **声明学习成本已被报错质量兜底**（正面发现）：port_ref 的 sourcePort 必须指向**本资产**声明的端口、
   条件字段必须 kind:"input"+type:"array"+of:"condition"、curve mode 枚举 linear/hold/smooth——
   三种声明形态我全部写错过一次，但编辑器每次都给出**精确到 path 的中文报错**，一次改对。
   初学者靠报错即可自助完成声明纠错。

## 5. 任务二：易用性走查（初学者视角）

走查路径 = 启动 → 打开工程 → 新建地图 → 放置 → 保存，逐环节核对入口与反馈。

**结论先行：低门槛成立。** 初学者最短路径 = 打开项目文件夹 → 新建地图 → 点选资产 → 点画布放置 → Ctrl+S，
全程有引导文案与精确报错兜底，不需要任何文档即可完成第一张地图。

- **启动**：项目选择页对空状态有完整引导（"还没有项目" + "选择包含 editor/editor_manifest.json 的
  游戏工程目录"），打开失败回选择页并说明原因。
- **新建**：画布空态给出两大按钮（新建地图 / 打开地图文件…）+ 状态栏同步提示"新建地图或打开已有文件以开始编辑"。
- **菜单结构**：文件 ▾ / 地图 ▾（新建/从游戏生成/重新生成/打开文件/重命名/复制整张/调整尺寸/内容与出口/画面预览，
  9 项语义分组清晰）+ 关卡/内容/资产三主入口 + 试玩配置/试玩地图/保存常驻顶栏。
- **保存链路防护完整**：Ctrl+S → 外部改动检测（digest 比对）→ 确认弹窗"磁盘上的地图与打开时不同"→
  覆盖保存确认 → 崩溃自动草稿（editor/drafts/）。保存中止的每种情况都有明确状态栏文案
  （"保存中止：…请重新检查后再保存"）。

- **键盘只剩必要入口**：快捷键速查弹窗（顶栏 ?）9 行覆盖撤销/剪贴板/翻转旋转缩放微调/框选/文件/返回/视图，
  其余全部交给鼠标与下拉——符合"极低门槛"取向。方向键微调、框选开关在状态栏可见（框选/跨层搬动/吸附/网格）。
- **报错质量是最大的易用性资产**：本次全部 20+ 种报错（声明纠错×3、批次拦截×2、防护探测×3）全部为
  精确中文+定位 path，初学者可完全自助纠错；无一处含糊或纯英文内部术语。
- **面板文案完整**：参考视图弹窗等复杂面板顶部都有说明文案（"拖动绘制热点，点击选中…"），
  字段标签为完整中文（视图 ID/参考图片/编辑屏幕布局/热点/跳转目标）。
- **画面证据**：logs-exp2/ 四张截图（24 层深景图渲染正常、塔防图格图语义正确、
  编辑器窗口整体 UI、参考视图弹窗）。

## 7. 结论

- **上限**：内容数据规模上限远未触及（100 层/1 万格/200 行 1.8 秒），防护体系在极限数据下依然精确拦截；
  三个边界语义（越界瓦片/负 parallax/画布不跟随）值得产品化确认，均非崩溃级缺陷。
- **易用性**：极低门槛成立——空态引导、菜单语义分组、保存防护链、中文精确报错四件事构成了
  "初学者不需要文档就能完成第一张地图并保存"的完整闭环。

## 8. 项目复核与处理

- **越界瓦片**：保留原始数据，可用于边缘延伸。统一校验现在按图层报告数量和示例坐标，按该层的生效拓扑判断，包括三角层的双列范围。缩小尺寸仍保留旧数据，显式裁剪走地图尺寸界面。
- **人工复核草稿**：空画布和地图菜单均可打开只读预览。支持选草稿、选地图和刷新版本，不会打断当前人工编辑，也不会把草稿当正式地图。
- **负视差**：画布平移已实现反向滚动，层管理本来就是可输入负数的数字框。保留这个能力，补上说明，并用实际相机位移验证。
- **压力测试**：边界探测改为核对返回值和候选数据，项目校验也改用 `validate(draft)`。修正后 16/16 通过。该结果证明所列规模可用，未测出最大容量。
