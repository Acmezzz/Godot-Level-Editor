# Ponytail Ultra 审查处理记录

对应 [源码审查](EDITOR_SRC_PONYTAIL_ULTRA_AUDIT_2026-11-28.md)。地图、图组、内容与游戏侧清单协议继续沿用原有结构。

| 审查项 | 处理结果 |
| --- | --- |
| #1 演出与字段预检 | 检查已填写的声明字段、步骤码、步骤字段及时间；保留未知扩展键和旧文件读取。 |
| #2 配对地图引用 | 从同级字段读取目标地图，沿内容分支传播上下文；有环时按内容与地图去重。 |
| #3 正式发布结果 | 正式文件写完即报告已发布；下一份草稿索引写不成时保留回执，同版本重试只整理草稿。 |
| #4 绑定顺序 | GUI 与 MCP 共用列表重编号，`index` 与 `data.order` 指定的位置须一致。 |
| #5 演出撤销 | 已落盘的演出写入进入内容撤销记录；演出窗和停靠面板支持撤销、重做，保留摘要冲突检查。 |
| #6 图组遮挡 | 普通地图和图组参照使用同一个整组顺序；排序值相同也不会反转。 |
| #7 默认图层 | 画布和 MCP 按同一规则解析省略的图层，查询返回实际落层。 |
| #8 停用资产 | MCP 不再新增停用实例或绘制停用图集；旧摆放与 ID 保留。 |
| #9 缩略图 | 同路径共享纹理；普通内容保存不重建缩略图缓存。 |
| #10 声明读取 | 对象查询、引用扫描、画布载入和批量预览在遍历外取声明；步骤也按执行码查表。 |
| #11 草稿历史 | 版本存索引，正文按摘要复用。旧草稿仍可读取，重开分支、发布和丢弃时回收不用的正文。 |
| #12 自绘格遮挡 | 层面板直接标明「仅实例」；瓦片需要遮挡时分前后层。保留自绘整层，未引入逐瓦片排序。 |
| #13 共用边界 | GUI 与 MCP 直接调用项目数据检查；正式写入共用提交计划执行，保留各自的序列化和收尾。 |
| #14 清理 | 移除孤立转发、常量和重复刷新；地图转换复用现有锚点计算。 |

规模回归使用 10 张地图、每张 12,000 格。只改一条内容后，版本索引小于 2 KB，只新增这一条内容的正文，10 份地图正文全部复用。

最终验收：Godot 4.7.2 干净副本导入通过；167 个语言服务器诊断目标零问题；123 个源码脚本编译通过；269 项数据测试、刷怪试点 24 项检查、四套图形制作工作流通过。MCP 用源码启动编辑器验收了全部 11 个工具，覆盖无效内容发布拦截、重复发布、截图、预览和试玩。未重新导出或验证 EXE。
