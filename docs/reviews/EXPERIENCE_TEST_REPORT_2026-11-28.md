## 3. 过程中发现与防护体系实证

测试脚本迭代中编辑器报过的全部错误（以及它们的正确性）：

- "缺少参数：draft"/"请先在编辑器中打开游戏工程"：流程前置要求，报错准确。
- "绑定需要已存在的实例码"：批内别名 `$xxx` 与跨批 ids 引用的语义差异被正确区分。
- "批次未应用：数据格式无效"（未知层码/非法 element kind）：**validate 门真实拦截**了 2 次坏数据，报错带精确 path（objects[2].layer / views[0].layout.elements[1].kind）。
- layer.put 的"指定 layer=修改、省略=新建"语义与文档一致；repeatable 未声明时拒绝重复绑定正确。
