# 2D 游戏编辑器：三份审查的修复与验收

本次处理 [src 对抗性审查](EDITOR_SRC_ADVERSARIAL_AUDIT_2026-11-28.md)、[真实制作与试玩](EDITOR_LIVE_AUTHORING_AND_USABILITY_2026-11-28.md) 和 [全流程制作体验](EDITOR_PRODUCTION_WORKFLOW_UX_2026-11-28.md)。继续使用原有的稳定 ID、清单声明、同级执行内容和地图／图组文档；没有为某一种游戏类型增设制作协议。

## 缺陷处理

| 审查问题 | 本次实现 | 验证 |
| --- | --- | --- |
| 改画幅可能保存一份下次打不开的清单 | 写盘前用新画幅检查已有屏幕布局，保留表单输入并显示失效字段。 | 正式全量验证通过；命名画幅和布局几何分别有回归。 |
| MCP 会清掉未提交的人工表单 | 会重建编辑器的正式发布、切工程检查人工表单和地图工作副本。只读预检不受此限制。 | 在导出包中打开图组表单，预检通过、正式发布被拒绝，核对正式内容仍未改动。 |
| 跨图与直接内容引用漏查 | 字段按声明语义枚举，兼容默认值、数组和记录；显式目标地图缺失与未指定上下文分别处理。正式入口也进入内容来向。 | 引用、字段、屏幕与流程回归；MCP 删除仍被绑定的内容未获许可。 |
| 地图槽等非实体入口缺少内容地图上下文 | 人工目标移除检查与 MCP 使用相同的内容上下文传播，从地图槽、绑定、配对屏幕和正式入口进入；继承按内容和地图分别去重。 | 两图继承同一份内容、有循环时结束且下游保留两个地图上下文。 |
| 窄画幅换父级跳位 | 把未创建专属变体的命名画幅也纳入换父级保位。 | 640 像素命名画幅换父级与解除父级都保留同一矩形。 |
| Windows 只改地图名大小写失败 | 使用共同的临时路径改名写入，避免把同一个物理文件当新旧两个目标。 | 导出包把 `Alpha.json` 改成 `alpha.json`，地图码不变。 |
| 层混合漏掉实体／几何 | 画布同层实际绘制节点继承层材质。 | 源码、编译与图形回归通过；没有逐材质、逐像素重测所有形状。 |
| 草稿截图未执行裁剪 | 草稿截图与其他目标共用裁剪和输出。 | 导出包分别核对整帧、32×32、边缘相交裁成 10×10、完全无交集返回错误。 |
| 错误触发时机可能通过校验 | 候选、编辑和校验共用时机声明；绑定写执行码，空值仍代表默认时机。 | 真实样例使用正确执行码完成触发，声明 ID 被拒绝。 |
| 试玩自动保存后仍显示未保存 | 成功保存更新地图标题和未保存标识。 | 保存和试玩路径通过图形工作流。 |
| 指定时间打开演出时读数不对 | 复用播放头更新路径，同步预览、读数和时间线。 | 1280×800 大样本实际打开 42 步演出，时间线和读数均到 0.55 秒，并在该时刻加步。 |

草稿独立保存各版本，查询读取当前版本，撤销重做沿用版本号。差异摘要展示字段路径；基线发生变化时明确标出，仍可另读候选文档。批量发布复用正式地图身份索引，正式覆盖保留上个版本。导出排除测试、取证素材和开发工具。资产诊断会指出无效的切片声明和比图集还大的有效切片；同一次清单检查复用相同图集的图像尺寸。

## 从开工到交付

| 阶段 | 作者可用的路径 |
| --- | --- |
| 开工 | 已有项目从地图、内容或屏幕直接进入；新图先设名称和尺寸，拓扑等设置可展开。 |
| 持续做图 | 项目地图可按近期、关联、固定和全项目打开。参照旧图选材时，可查看已用、用途、标签和收藏，回当前地图放置。 |
| 继续编排 | 同型实例通过图层和坐标区分；功能列表显示真实序号、时机、显示名和启用状态。编辑区可调宽；插入后滚到新条目。可按兼容时机和本图使用挑选，可复用到明确选中的同资产实例。 |
| 跨图与 UI | 一处配置图组顺序、范围和事件；在图组上切换适用底图来预览，不改变当前写入对象。屏幕布局和参考热点均可直接打开。 |
| 长演出 | 时间线和可定位的步骤摘要同处显示。可以按时刻添加、复制一段、整体平移或重新分布起点；重叠提示按需展开。 |
| 批量维护 | 内容来向区分绑定、内容、屏幕和项目等来源。批量改绑只改勾选的正式实例绑定，先生成草稿，由作者核对后发布。 |
| 收尾与 AI | 「检查与试玩」显示正式入口、结构问题和最近运行回执；从可定位的问题返回地图、内容、步骤、屏幕或图组。MCP 可按范围查资产、功能、跨图对象和绑定，预览后再发布。 |

## 验收记录

- Godot 导入通过。164 个脚本诊断零问题，121 个源码脚本编译成功，261 项单测、24 项 Pilot 检查及制作工作流、卡片、网络、屏幕导航集成均通过。
- 源码版和重新导出的 Windows EXE 均通过 MCP 11 工具集成验收，涵盖读写草稿、预检、发布、截图、实际试玩、冲突拦截和 Windows 改名。
- Windows 实际输入已走通侧视地图、固定 HUD、共享图组的覆盖顺序和碰撞区别、音频和对白、24 层连续显隐与转场、等距路线解谜、六边格货物运输及独立设置屏入口。目录为 `tools/shots/production-finish/live/`。
- 大项目图形复验使用隔离副本：120 地图、1,152 资产、124 功能；从参照图选材，给已有 36 条绑定的实例在 #18 后插入，确认 #19 可见且旧 ID／顺序不变；42 步演出定位并添加。截图位于 `tools/shots/production-finish/large-ui/`。这些界面动作由测试脚本触发，不能代替新手观察测试。

报告中的任意关系批量重接、命名时间轨和段标记不是本次已交付功能。键盘单独完成全流程、大字体模式以及新手独立上手尚未做系统实测；游戏侧自己发布的生产包仍须用其真实工程验收。这次已经实际验证的是编辑器 EXE、MCP 与独立测试游戏。
