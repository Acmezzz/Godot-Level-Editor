# 内容编写指南（给关卡/剧情作者）

> 面向"想在地图里加一段对话、一段演出、一个商店"的操作说明。
> 字段规则与游戏侧契约见 `docs/content-development-standard.md`；这里只讲怎么用编辑器做出来。

---

## 0. 一句话流程

**先在地图上放实体 → 选中它建内容组 → 在右侧内容抽屉里就地写对话/事件/商店 → 校验 → 试玩。**

编辑器是**实例为主、库为辅**：你在实体身上配内容，内容本身仍是带 id 的资源，所以同一份可以给多个实体共用。

---

## 1. 两个入口，什么时候用哪个

| 入口 | 在哪 | 什么时候用 |
|---|---|---|
| **内容抽屉** | 选中实体 → 属性面板「编辑内容（对话/事件/商店）」 | **主路径**。你在摆这张图，想给这个 NPC 配台词、给这块地绑演出 |
| **内容库**（全屏） | 顶栏「内容库」 | 浏览全部资源、批量整理、重命名、删除、跨图复用 |

两者读写同一批 JSON（`<游戏工程>/content/<种类>/<id>.json`），任一处改动另一处立刻能看到。

---

## 2. 主路径：从实体开始

1. 画布上放一个 NPC（调色板选实体 → 盖章）。
2. 用「属性」工具点它。
3. 属性面板「定义」区 → **＋ 为此实体创建内容组**。
   会自动生成 `grp.<地图名>.<实体id>`，并在 `content/defs/` 里落一个文件，实体同时挂上它。
4. 右侧**内容抽屉**打开，三个槽位：对话 / 互动事件 / 商店。
5. 每个槽位：
   - **新建** → 自动建一份资源（id 形如 `grp.map1.e_7.dialogue`，一眼看出归属），直接进入编辑
   - **选已有…** → 挂库里已有的资源（共享）
   - **编辑** → 就地改内容，地图和实体始终可见，不用来回跳页

内容组 id 带地图名和实体 id 只是**便于识别**，它仍然是一个普通 `defs` 资源，别的实体也能引用同一个。

---

## 3. 多段内容 + 一次性 vs 可重复

**一个槽位可以挂多段。** 这解决了"A 有初遇对话、闲聊对话、任务对话"这类结构——
不需要额外的字段，靠**顺序 + 条件 + 一次性**就能表达。

在内容抽屉里，每个槽位有 **＋ 条目**。加进去的条目按顺序排列，每条有自己的：

| 控件 | 数据 | 含义 |
|---|---|---|
| 播完不再出现 | `"once": true` | 这条播完写 `<组id>.<组件>.<资源id>.done`，之后跳过 |
| 前置 flag | `"when": "met_smith"` | 该 flag 为假时跳过这条 |
| ↑ ↓ | 数组顺序 | 调整匹配优先级 |
| × | — | 只从内容组里移除引用，**不删资源文件** |

**匹配规则：从上往下，第一条「条件满足且没播过」的胜出。**

典型配法（初遇 → 闲聊 → 兜底）：

```
1. dlg.first     once=true               ← 第一次见面，说完作废
2. dlg.idle      when=met_smith          ← 认识了才出现
3. dlg.default                            ← 都不命中时的循环台词
```

全部不命中 = 这个槽位当前"没话说"，游戏不弹对话。所以**最后一条通常不放条件**。

只放一条时，行为和你以前用的完全一样。

| 设置 | 游戏行为 |
|---|---|
| 不勾「播完不再出现」 | 每次互动都播这一条 |
| 勾上 | 播完不再命中这条，落到下一条 |

**文件永远留着。** 想改回可重复，取消勾选即可；想改台词，随时进编辑。这和"用完就删"是两件事——
RPG 里"说完这段他就不说了"是内容还在、只是不再触发。

一个内容组里可以混着来：对话第一条一次性、商店永久可用。

## 4. 写对话的细节

节点图，不是字符串：

```json
{"start": "n1", "nodes": [
  {"id": "n1", "speaker": "s1", "text": "要买点什么？", "next": "n2"},
  {"id": "n2", "text": "……", "choices": [{"text": "看看货", "next": "shop"}, {"text": "算了", "next": "end"}]},
  {"id": "end", "end": true}
]}
```

- **起始节点**决定从哪句开始（不是数组第一个）。
- **说话者为空 = 旁白**。要人名/立绘，先在「说话者」区加一条（`s1` + 显示名）。
- **下一节点**留空 = 这句说完结束。
- **选项**每条 = 文本 + 目标节点 + 可选 `action`（如 `open_shop`）。
- 改节点 id 会让引用悬空，校验立刻报红。

校验查：起始节点存在、`next` 不悬空、有没有走不到的节点、有没有可达的终止。

---

## 5. 写演出的细节

```json
{"once": true, "steps": [
  {"type": "camera_focus", "target": "e_42"},
  {"type": "dialogue", "dialogue": "dlg.smith"},
  {"type": "wait", "seconds": 0.5}
]}
```

**动作清单由游戏工程提供**（`content/schema/actions.json`）。编辑器读它生成下拉和参数控件：
布尔→开关，数值→数字框，引用类→资源下拉（列出该种类现有 id），其余→文本框。

加一个新动作（比如震屏）只改游戏的 `actions.json`，编辑器不用改代码。

`entity_ref` 指地图内实例，编辑器不知道别的图，仍手填。

---

## 6. 配商店

```json
{"currency": "gold", "entries": [{"item": "item.ore", "price": 12, "stock": 5}]}
```

库存 `-1` = 无限。清单有 `items` 时物品是下拉。校验查重复物品、未知物品、负价格。

---

## 7. 放触发区

触发区是编辑器**内置种类**，不需要游戏工程声明，也不需要贴图。

1. 实体调色板选 **触发区**，在地图上盖一块。默认 2×2 格、进入触发、只触发一次。
2. 属性面板「触发区」区：尺寸（宽×高，格）、触发方式、绑定事件、只触发一次、前置 flag。
3. 画布上**橙色 = 没绑事件**（这块地是死的），**蓝色 = 绑好了**，左上角标 `事件id · 触发方式`。

没绑事件的触发区会被校验报 error。

---

## 8. 复用：让多个实体共享同一份内容

这是"库为辅"的用法，适合**店员、告示牌、通用宝箱**这类重复内容：

1. 先建一份资源（在任一处建，内容库或抽屉都行）。
2. 别的实体 → 内容抽屉 → 该槽位 **选已有…** → 挑那一份。
3. 之后改一次，所有引用它的实体一起变。

反过来，如果某个实体要说不一样的话，就给它 **新建** 一份（id 会带它自己的归属），
不要复用——避免为了一个特例把别处的台词也改了。

---

## 9. 改名字 / 删资源

在**全屏内容库**里操作：
- **重命名**：改文件名，旧文件删除。引用不会自动改，会变成悬空。
- **删除**：先扫全部引用，列出"还有谁在用"再确认。没确认之前文件不动。

删除后遗留的引用会被校验页报成悬空引用。

**改显示名，不动 ID**：对话/事件/商店有可选 `name` 字段（定义本来就有）。
想改"打招呼"这类给人看的名字，改 `name` 就行——随时改、零引用变化。
`id`（文件名）才是游戏端身份；改 id = 上面的"重命名"（要扫引用），
只在真要换身份时才做。

---

## 10. 校验与试玩

- 校验页把内容问题和地图问题合并展示，点击可定位到具体地图/实体。
- 触发区没绑事件、定义种类与实体不符、对话悬空、商店未知物品——都是 error。
- 游戏侧要跑起来，还需要按 `docs/content-development-standard.md` 第 10 节完成对接
  （`EventRunner`、`DialogueRunner`、`trigger_zone` → `Area2D`）。

---

## 11. 常见问题

| 现象 | 原因 |
|---|---|
| 属性面板没有「创建内容组」按钮 | 没选中实体，或地图没打开 |
| 事件编辑器动作下拉是空的 | 游戏工程缺 `content/schema/actions.json` |
| 定义下拉里没有我建的定义 | 定义的 `kind` 与当前实体种类不一致（下拉只列同种类的） |
| 触发区在调色板里看不到 | 内置种类不走缩略图过滤；若仍看不到，检查清单加载是否成功 |
| 改了台词，试玩没变 | 确认槽位「编辑」里校验通过；游戏读的是 `content/dialogues/<id>.json` |
| 想让 NPC 说完一段就不再重复 | 槽位里勾「播完不再出现」（`once: true`），不要删资源 |
| 删除资源后校验报一堆错 | 正常——悬空引用，按提示改掉或重新指向 |
