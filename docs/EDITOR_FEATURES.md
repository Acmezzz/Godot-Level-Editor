# BIRD 关卡编辑器 — 功能文档

> 独立 Godot 4.7.2 工程（`D:\Game\BIRD\Level Editor`），入口场景 `src/editor.tscn`，主脚本 `src/app.gd`。
> 编辑器不依赖游戏工程资源，只读 `<游戏项目>/editor/editor_manifest.json`、`maps/*.json` 与 `content/<功能id>/*.json`。
> 本文按 2026-11-19 的实际代码重写；凡文档与代码冲突，以代码为准。

---

## 1. 总体架构

```
src/
├── app.gd                 宿主：项目选择、快捷键、模式切换、跨控制器委托
├── editor.tscn            入口场景（只挂 app.gd，界面全部代码构建）
├── manifest.gd            清单读取（EditorManifest）：路径/命令/角色/功能声明
├── manifest_validation.gd 清单结构校验
├── map_store.gd           地图 JSON 读写（原子写、历史轮转、mtime 缓存、事务）
├── map_data_validation.gd 地图数据结构校验（含实例 functions 结构）
├── map_export.gd          预览图 PNG 渲染 + 统计文本
├── playtest.gd            试玩命令拼装、子进程启动与存活跟踪
├── core/
│   ├── constants.gd       共享常量（INVISIBLE_CELL 等）
│   ├── editor_state.gd    状态流唯一写入口 _apply_state + UI 派生 _sync_ui
│   ├── undo_history.gd    快照式撤销/重做（80 步，JSON 字符串快照）
│   └── side_actions.gd    改名/复制地图、按名开图、按 id 删实体
├── canvas/
│   ├── editor_canvas.gd   画布宿主：load_data、图层节点、相机、序列化、委托
│   ├── canvas_draw.gd     绘制：网格/幽灵/连线/占位框/触发区/选区/粘贴预览
│   ├── canvas_input.gd    鼠标输入路由：缩放平移、涂/擦、框选、拖拽
│   ├── tool_ops.gd        按层语义执行左键（放置 / 涂刷）与右键擦除
│   ├── selection_ops.gd   选区、剪贴板、区域复制粘贴搬迁、翻转
│   ├── collision_view.gd  碰撞格可视化（按类型分色、斜坡画三角）
│   └── tileset_cache.gd   TileSet 构建缓存（路径 + tileSize + 图集 mtime）
├── content/
│   ├── content_store.gd   内容资源读写：路径解析、原子写、枚举
│   ├── content_id.gd      分层身份码：地图/实体/实例 4 位，内容 6 位
│   ├── builtin_kinds.gd   内置实体种类（trigger_zone）注入/剥离
│   └── def_model.gd       数值三层合并（实例 > 定义 > 清单）
└── ui/
	├── ui_theme.gd        设计系统：全部颜色/圆角/字号/控件样式
	├── ui_kit.gd          可复用构件：按钮变体、徽章、字段行、空状态
	├── editor_layout.gd   关卡视图搭建：顶栏/左栏/画布/选中信息条/状态栏
	├── project_shell.gd   项目工作台外壳：内容 / 资产 两个全屏视图
	├── top_bar_nav.gd     共享顶栏片段：地图 ▾ + 关卡/内容/资产
	├── palette_panel.gd   瓦片调色板（类别 → 资产两级导航）与实体列表填充
	├── map_file.gd        地图生命周期：新建/打开/保存/改名/草稿/尺寸/导出/试玩
	├── props_panel.gd     只剩「从地形生成碰撞」弹窗
	├── content_editor.gd  内容编辑器（左实例 / 中预览 / 右实例与功能）
	└── asset_panel.gd     资产目录（图鉴详情 + 实例分布）
```

设计原则：**清单驱动**。图层、图集、实体类型、字段与数值声明、功能声明、试玩命令全部来自清单；
编辑器只编辑数据，不硬编码游戏内容。

架构模式：`app.gd` 与 `editor_canvas.gd` 是两个**宿主**，只保留引导代码与同名薄包装，功能实现在
`RefCounted` 控制器里（`preload(...).new(self)` 装配，经 `app.` / `cvs.` 访问宿主状态）。
外部调用点一律走宿主同名包装器，拆分对调用方透明。

> 注意：`app.gd` → 控制器 → 再一层控制器 的委托链里，凡是含 `await` 的函数，**每一层都必须 `await`**。
> 漏一层协程会被丢弃、调用方立刻返回（语法合法，`--check-only` 查不出）。

## 1.1 快速上手

**启动**：用 Godot 4.7.2 打开本工程（主场景 `src/editor.tscn`）直接 F5；或
`godot --path "D:\Game\BIRD\Level Editor"`。

**首次启动**：选游戏项目文件夹（内含 `editor/editor_manifest.json` 与 `maps/`）；下次自动加载
（`user://settings.cfg`）；清单读取失败在选择页直接给出错误说明。

**日常流程**：

1. 顶栏左侧「设置 ▾」→ 新建地图（填名字）或打开已有地图。
2. 左栏顶部「层：…」下拉选图层。**层决定一切**：地形/装饰层 = 刷瓦片，碰撞层 = 画碰撞块，
   实体层 = 放实体。没有工具按钮要选。
3. 左栏下方资产列表跟着层类型切换：地形/装饰 → 瓦片，实体 → 实体；碰撞层显示类型/形状下拉。
4. 画布上左键拖动 = 放置/涂刷，右键拖动 = 擦除/删除。
5. 点选实体后画布下沿出现信息条（类型 + e_N + 内容状态 + 「在工作台编辑 →」）。
6. `Ctrl+S` 保存；顶栏「▶ 试玩」保存并在游戏里跑当前地图。

**三个平级面板**：`关卡`（画布）/ `内容`（给实例挂功能、填内容）/ `资产`（图鉴、实例分布），
`Esc` 从后两者回关卡编辑器。

## 2. 项目接入

| 功能 | 说明 |
|---|---|
| 选择项目文件夹 | 启动时无上次记录则显示选择页，`FileDialog` 选目录 |
| 清单校验 | 读 `<项目>/editor/editor_manifest.json`；缺失/解析失败/结构无效都进错误页，附问题路径 |
| 记住上次项目 | 写 `user://settings.cfg`，下次自动加载 |
| 项目名展示 | 顶栏最左显示 `projectName` |
| 路径推导 | 读后自动补 `_dir`、`_maps_dir`、每个图集的 `atlas_abs`、`_warnings` |
| 清单版本 | 缺 `version` 补 1（结构演进时的迁移锚点） |
| 内置种类合并 | `builtin_kinds.merge_into` 把 `trigger_zone` 补进 `entities`（`builtin=true`），写盘前剥离 |
| 实体身份码补发 | `entities[].code` 缺失时补发 4 位码，随清单保存写回 |

清单里编辑器实际消费的键：

| 键 | 用途 |
|---|---|
| `projectName` | 顶栏品牌 / 窗口标题 |
| `tileSize` | 瓦片像素尺寸（默认 16） |
| `screenSize` | 游玩视野预览框尺寸（默认 `[640,360]`） |
| `tiles[]` | 图集：`id` / `name` / `atlas` / `palette[]`（多图集时索引即 `source_id`） |
| `layers[]` | 图层：`id` 只能是 `terrain` / `decor` / `collision`；`type` = `tiles` / `grid` |
| `entities[]` | 实体类型：`id` / `name` / `thumb` / `prefab` / `editorSize` / `stats[]` / `fields[]` / `role` / `code` |
| `functions` | 功能声明：`{fnId: {name, fields[]}}` 或 `[{id, name, fields[]}]` |
| `playCommand` | 试玩命令模板，支持 `%mapfile%` / `%projectpath%` |
| `godotExe` | 可选：覆盖 `playCommand` 里的可执行文件（支持 `%projectpath%`） |
| `contentDir` | 可选：内容根目录，默认 `content` |

**图层支持面**：`terrain` / `decor`（tiles）+ `collision`（grid）+ 实体层（索引 = `layers.size()`）。
清单校验会拒绝其他 `id`，缺推荐层只警告。碰撞层 id 与类型（solid/one_way/ladder/hazard）由游戏侧
`map_loader` 消费，两边一一对应。

> 游戏工程该怎样声明清单/读地图/实现功能，见 **[GAME_SIDE_STANDARD.md](GAME_SIDE_STANDARD.md)**（数据契约唯一权威）。

**实体占位尺寸**：`editorSize: [w,h]` 优先；否则读 `prefab` 的第一个碰撞形状
（Rectangle 用 `size`，Circle 用 `radius*2`，Capsule 用 `radius*2 × height`）；都没有 = 用缩略图原始尺寸。

**角色声明**：`entities[].role` = `portal` / `exit` / `landing` / `trigger`（连接语义标签）。
未声明时按 scene id 回退（`portal` / `exit` / `spawn_point` / `trigger_zone`）。
画布绘制出口角标、落点描边都按 role 判定，不再硬编码 scene id。

## 3. 地图管理

顶栏左侧「**设置 ▾**」容纳全部地图级动作（地图**切换**是另一件事，在「地图 ▾」里）。

| 功能 | 说明 |
|---|---|
| 新建地图 | 弹窗填名字 → `120×56` 空图，出生点 `(2,2)`；同名文件已存在则拒绝 |
| 打开地图 | `FileDialog`，默认定位 `maps/`，只显示 `*.json` |
| 保存 | `Ctrl+S` 或菜单「保存」；写 `<项目>/maps/<名>.json`（制表符缩进 JSON） |
| **原子写盘** | 先写 `.tmp` 再 rename；中途崩溃不留半截 JSON |
| **历史轮转** | 正式保存前把当前文件拷进 `maps/.history/<名>.json.1..3`（`.1` 最新），备份失败不阻断保存 |
| 重命名地图 | 弹窗输入新名；**纯改名，不迁移跨图引用**；原图未落盘时按新名直接写盘 |
| 改名防覆盖 | 目标名已存在 → 拒绝 |
| 调整尺寸 | 改 `meta.w/h`（8–4000 格）；裁剪只改边界，不删已画内容 |
| 导出 | PNG 预览（1–16 px/格）+ 统计文本 → `<项目>/editor/exports`；可一键批量出全部地图（批量精度上限 4 px/格） |
| **未保存拦截** | 新建 / 打开 / 切图 / 关窗口时有未保存修改 → 确认框；取消则中止 |
| **自动草稿** | 有未保存修改且距上次保存超过 2 分钟 → 写 `<名>.autosave.json`；放弃修改的确认框会打印草稿路径 |
| **外部改动检测** | 打开后磁盘 mtime 变了 → 保存时提示「本次保存覆盖了外部改动」 |
| 地图名校验 | 拒绝 `/ \ : * ? " < > \|`、`..`、点开头/结尾、`con/prn/aux/nul`；路径必须仍在 maps 目录内 |
| 读取容错 | 文件打不开 / JSON 非对象 / 结构校验失败 → 状态栏报错并附问题条目，不崩溃 |
| 格式版本 | 当前 `FORMAT_VERSION = 3`；读老图自动升级（实体与出生点坐标取整），保存写回新版本 |

地图 JSON（与游戏侧 `MapLoader` 同构）：

```json
{
  "version": 3,
  "meta": { "name": "level_1", "w": 120, "h": 56, "code": "K7QM" },
  "spawn": [2, 2],
  "terrain": [[x, y, atlas, ax, ay]],
  "decor":   [[x, y, atlas, ax, ay]],
  "collision": [[x, y, "one_way", "r45"], [x, y]],
  "entities": [
	{ "scene": "crawler", "id": "e_1", "code": "B3XD",
	  "x": 10, "y": 8, "flip_h": false,
	  "props": { "hp": 7 },
	  "functions": [{ "fn": "dialogue", "content": "K7QM-D4L3-B3XD-dialogue-A9FK2P",
					  "name": "初遇", "order": 0, "parallel": false }] }
  ]
}
```

约定：

- `terrain` / `decor` 第 3 位是图集索引（= `tiles[]` 下标 = TileSet `source_id`），4/5 位是图集内格坐标。
- `collision` 只有类型非 `solid` 或形状非矩形时才追加第 3/4 位，缺省值零冗余。
- 实体 `props` 保留所有未知键（只有空值被丢弃），不做白名单剥离——手工预留字段不会在保存时蒸发。
- 实体 `x/y` 用 `floori` 换算，负坐标不会每次保存向 0 漂移。

## 4. 画布与图层

### 4.1 层下拉（左栏唯一输入决定者）

左栏顶部「层：…」按钮弹出的菜单按清单 `layers` 逐层生成，每层一行：**层名 + 👁 显隐 + 🔒 锁定**。
选中某层即切换画笔语义：

| 层类型 | 左键 | 右键 | 左栏内容 |
|---|---|---|---|
| `tiles`（地形 / 装饰） | 放置当前瓦片，拖动连续涂 | 擦除，拖动连续擦 | 瓦片调色板 |
| `grid`（碰撞） | 画碰撞块（类型 + 形状随下拉） | 擦除碰撞 | 碰撞类型/形状下拉 + 「自动生成碰撞…」 |
| 实体层 | 放置当前实体；空白处拖动 = 框选 | 删除命中的实体 | 实体列表 |

**图层显隐**只影响显示，不影响数据；**图层锁定**在写入入口（涂/擦/放置/拖拽/区域操作）逐处守卫，
绕过 UI 直调也会被拦。换图时显隐/锁定清空（撤销恢复同图时保留）。

### 4.2 瓦片调色板（两级导航）

- 顶层：多图集时先列**图集**，钻入后列该图集的**类别**，再进**资产**；单图集直接进类别层。
- 类别名优先取 `palette[].cat`，无 `cat` 用图集条目名（一个图集 = 一个默认类别），都没有 → 「未分类」。
  类别行显示「▶ 类别名（数量）」，进入后首行是「← 返回」。
- **最近使用（MRU）**置顶，会话内最多 8 格，键为 `atlas:x,y`。
- 缩略图 40×40（纹理缓存按图集索引 + 格坐标复用）；左栏宽 200px 时 3 列 × 56px，长名省略号 + tooltip。
- 清单没配 `palette` 时退回「整张图集逐格铺满」，每格都是可选瓦片。
- 装饰层没有独立资产清单：切到装饰层时清空列表并给提示。

### 4.3 碰撞层

- 左栏两组下拉：**类型** `solid`（实心）/ `one_way`（只碰顶面）/ `ladder`（梯子）/ `hazard`（伤害）；
  **形状** 矩形 / `r45`（右高斜坡）/ `l45`（左高斜坡）。
- 碰撞格数据上是 `collision` 那个 TileMapLayer 的隐形格（`INVISIBLE_CELL = (4,0)`），
  但显示交给专属节点 `CollisionView`：按类型分色（solid 红 / one_way 琥珀 / ladder 青 / hazard 品红），
  斜坡画三角形。直接显示 TileMapLayer 会画出图集那格灰白分块。
- 类型/形状只在非缺省时写入地图（`solid` + 矩形 → 只写 `[x,y]`）。

### 4.4 从地形生成碰撞（辅助）

左栏碰撞层的「自动生成碰撞…」弹窗：

| 策略 | 行为 |
|---|---|
| 全部地形格 | 每个有地形的格子都生成 |
| 仅顶部表面 | 只给「上方无地形」的格子生成 |
| 仅外轮廓 | 只给四邻有不空位的格子生成 |

可选「先清空现有碰撞再生成」；只写碰撞层、不改地形；整件事一个撤销步；碰撞层锁定时拒绝。
手动摆放仍是首选方式。

### 4.5 视图与画布绘制

- 滚轮缩放（0.5×–6×，以鼠标为锚点），中键拖动或**空格 + 左键**平移。
- 状态栏右侧「网格」开关；碰撞显示跟随图层显隐。
- 画布绘制内容：网格、地图边界、幽灵预览（瓦片范围框 / 实体缩略图 + 占位框 / 内置种类 2×2 矩形）、
  出生点十字（实体层实色、其余层淡色）、游玩视野框（鼠标处 + 出生点各一个 `screenSize` 框）、
  实体引用连线（同图黄线 / 跨图蓝紫线）、出口 ↗ 角标、传送落点描边、选中高亮、框选矩形、
  多选外接框（含「N 个实体 · 拖动可整体移动」提示）、实体实际占位框、触发区矩形、区域选区轮廓、
  区域拖动/粘贴幽灵预览。
- 没打开地图时禁用全部编辑交互，画布中央给引导。

## 5. 地形与碰撞编辑操作

| 功能 | 说明 |
|---|---|
| 涂刷 | 左键单格或拖动连续；笔刷边长 `brush_size`（默认 1，`_brush_cells` 以光标格为中心铺边长方形） |
| 擦除 | 右键单格或拖动连续擦 |
| 矩形填充 | **已删除**（用户要求），不再提供 |
| 图层锁定守卫 | 涂/擦/放置/拖拽/区域操作全部检查当前层锁 |
| 隐藏格 | `INVISIBLE_CELL` 作为碰撞占位，调色板自动跳过 |
| 旧格式兼容 | 地图无 `collision` 键时用 `terrain` 兜底生成碰撞 |
| 不做自动拼接 | 有意手动选格，不做 autotile |

## 6. 实体编辑

### 6.1 放置与选中

| 功能 | 说明 |
|---|---|
| 实体列表 | 清单 `entities`（含内置 `trigger_zone`）；无缩略图的实体不进列表，但内置种类例外（它们必须放得出来） |
| 放置 | 实体层左键点格 → 落一个 Sprite2D 占位，位置吸附格中心 |
| 放置即选中 | 放下后立刻发 `entity_selected`，「放置 → 配置」不断档；连放不受影响 |
| 实例 id | 自动分配 `e_N`；载入时继承原 id 并推进计数器 |
| **安全空洞复用** | 发号前做全工程引用扫描，确认最小空号没被任何地图/内容引用才复用，否则高水位 +1 |
| 实例身份码 | 每个实例带 4 位 `code`（存在于实体 meta，随地图保存），改名/换 id 不变 |
| 单选 | 点实体 → 选中并在画布下沿出信息条 |
| 框选 | 状态栏「框选」开关打开后左键拖动 = 框选；未开时 `Ctrl+拖动` 兼容。选中后外接框内按下可**整组拖动**，松手各自吸附格点，一次拖拽一个撤销步 |
| 命中判定 | 按实体**占位尺寸**做外接框命中（不是写死 16/20 px），命中多个取中心最近者 |
| 拖拽移动 | 按住实体拖动，松手吸附格点；一次拖拽一个撤销步 |
| 删除 | `Del`，或实体层右键点实体 |
| 朝向翻转 | `F` toggle 单选或框选集合的 `flip_h`，一个撤销步；写入地图 `entities[].flip_h` |
| 方向键微调 | 有选中时整格移动（`Shift` = 4 格）；1 秒内的连续按键合并成一个撤销步 |
| 复制粘贴 | `Ctrl+C` / `Ctrl+V` 保持相对布局，粘到光标处吸附格点；`props` 与 `functions` **深拷贝**，副本互不影响；内部引用重映射到新 id |
| 原位复制 | `Ctrl+D` 偏移 1 格复制，带 `props` / `functions` / `flip_h`，新号照发 |
| 剪切 | `Ctrl+X` 复制进剪贴板并删除选区，整件事**一个**撤销步 |
| 实体大纲 | **已删除**（右侧五页签面板整体删除）；找实体靠画布与内容编辑器左列 |
| 属性面板 | **已删除**；参数编辑在内容编辑器「固定功能」块与资产目录里 |

### 6.2 选中信息条

画布下沿浮一条极简信息条：`类型名 e_N` + 内容状态 + 「在工作台编辑 →」（`Enter` 同效）。
它**不是**属性表单——参数属内容，归内容编辑器与资产目录。没选中时整条隐藏。

### 6.3 区域编辑（瓦片 / 装饰 / 碰撞 / 区域内实体）

| 操作 | 说明 |
|---|---|
| 框选区域 | 非实体层 + 框选开关（或 `Ctrl+拖动`）→ 画金色选区轮廓 |
| 区域复制 | `Ctrl+C` 捕获地形 / 装饰 / 碰撞 / 区域内实体四段快照（实体按相对偏移存） |
| 区域粘贴 | `Ctrl+V` 进入幽灵预览（四层都画），左键落位，右键或 `Esc` 取消；实体重新发号并重映射引用 |
| 区域剪切 | `Ctrl+X` 复制 + 擦源，一个撤销步；任一图层锁定即整体拒绝（部分跳过会让剪贴板与实际删除不一致） |
| 区域拖动 | 在选区内按下拖动整块；**松手才**「推撤销 → 擦源 → 写目标」，中途取消不留半截状态 |

### 6.4 出生点

- 出生点画成绿框 + 十字；只在实体层可拖（其余层淡色，避免在地形层误导成可点），拖动前推撤销快照。
- 出生点位置存 `spawn: [x,y]`（格坐标）。

### 6.5 触发区（内置种类）

`trigger_zone` 由编辑器提供，游戏工程清单不需要声明：

- 并入清单（`builtin=true`，固定实体码 `TZ99`），保存清单时剥离，不污染游戏工程。
- 没有 `thumb` 也出现在实体列表里；放置时画 2×2 矩形幽灵，落下带默认
  `props { w:2, h:2, mode:"enter", event:"", once:true }` 并把位置推到矩形中心。
- 无父属性表单后，`w/h/mode/event/once/require_flag` 不再有专用编辑控件；
  这些键仍必须随地图保存——`undo_history.TRIGGER_PROP_KEYS` 显式放行，否则保存会静默丢字段。
- 画布绘制：半透明矩形 + 左上角标签 `事件id · 触发方式 · 一次`；未绑定时橙色并显示「(未绑定事件)」，
  绑定时蓝色。

## 7. 内容系统（实例 → 功能 → 内容）

### 7.1 模型

- **功能由项目侧实现**，编辑器只暴露「可编辑内容」接口。
- 功能在清单顶层 `functions` 声明：`{fnId: {name, fields:[...]}}`。`fields` 与实体 `stats/fields` 同构
  （目前支持 `int` / `float` / `bool` / 其余按 `string`）。
- **实例绑定**存在实体 meta / 地图 JSON 的 `functions` 数组里：

```json
"functions": [
  { "fn": "dialogue", "content": "<内容ID>", "name": "初遇", "order": 0, "parallel": false }
]
```

| 字段 | 含义 |
|---|---|
| `fn` | 功能 id，必须对应清单 `functions` 声明（未声明的只告警，允许先放数据后补实现） |
| `content` | 内容条目 id；空串 = 还没填（界面显示「未填」），不是错误 |
| `name` | 内容显示名（列表读这个） |
| `order` | 组内顺序；**顺序即执行顺序** |
| `parallel` | 与前一项同时触发 |

- **内容文件**：`<项目>/content/<功能id>/<内容id>.json`，结构
  `{id, function, name, fields:{字段id: 值}}`。`fields` 子字典留给以后扩展。
- **复用 = 复制出新 ID**：库里已有的内容可以被复制成一条新内容追加到当前实例，不复用同一份文件。

### 7.2 分层身份码

五段：`地图-实体类型-实例-功能-内容`。

| 段 | 长度 | 载体 | 发放时机 |
|---|---|---|---|
| 地图 | 4 位 | 地图 `meta.code` | 首次载入该图时补发 |
| 实体类型 | 4 位 | 清单 `entities[].code` | 读清单时补发；内置种类固定（`TZ99`） |
| 实例 | 4 位 | 实体 meta `code`（随地图保存） | 放置/载入时补发 |
| 功能 | — | 清单 `functions` 的 id | 声明即身份键（不是显示名） |
| 内容 | 6 位 | 内容 id 末段 | 创建内容时随机发放 |

字符集 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（去掉易混的 I/O/0/1）。
**名字完全退出 ID**：地图名、类型名、`e_N` 都只是展示层，改名不影响任何运行时引用。
任一段缺失时 `content_id()` 返回空串，不产出脏 ID；`unique()` 冲突时只换末段内容码。

### 7.3 内容编辑器（工作台 →「内容」）

三列布局：

| 列 | 内容 |
|---|---|
| 左（220px） | 本图实例列表：类型名 + `e_N` + 状态点；整行是按钮，点击与画布双向同步。`e_N` 按数字排序 |
| 中 | 只读画布预览：重绘网格 + 真实地形/装饰瓦片 + 实例缩略图/色块 + 选中框；滚轮缩放（鼠标锚点）、中键平移、左键点选/悬停 |
| 右（360px） | 选中实例：类型名 + `地图名.e_N` + **固定功能**（清单 `stats` → SpinBox/LineEdit，写实例 `props` 覆盖）+ **附加功能**列表 + 选中项的内容表单 |

**附加功能行**：`① 功能名 [内容名] ⟳并行 [库] ✕`

| 操作 | 说明 |
|---|---|
| 点行 | 展开该功能的内容表单 |
| 「+ 添加功能 …」 | 列出清单 `functions` 声明的全部功能（声明 = 开发契约，编辑器只读） |
| 「库」 | 列同功能的全部内容条目，选中一条 → **复制成新 ID** 追加到实例末尾并选中；跨功能不列（字段声明不同，复用没意义） |
| 「⟳并行」 | 切换该条的 `parallel` |
| 「✕」 | 只解除绑定，**内容条目留在库里**（删绑定 ≠ 删内容） |

**内容表单**：只读 ID（未创建时显示「未创建」）+ 显示名 + 按 `fields` 声明渲染的字段。

**写盘策略（重要）**：

- 内容编辑器**不做内存草稿**，改动即时写盘。
- 首次修改任意字段时创建内容条目：生成分层 ID → 写空内容 → 回写实例绑定（`_ensure_content`）。
- 文本类字段在**失焦/回车**提交（不每击键写盘）。
- `SpinBox` 这类连续控件只在**失焦 / 回车 / 点上下箭头后松手 / `commit()`** 时写盘；
  离开内容页（Esc、切视图）时 `_set_mode` 先调 `content_editor.commit()` 冲刷未提交值。
- 写盘失败：状态栏 + 右栏红色徽章双重提示，不静默吞掉。

### 7.4 资产目录（工作台 →「资产」）

与关卡/内容平级的第三个面板。左列图鉴列表（48/40px 图标），右侧详情：

| 区块 | 内容 |
|---|---|
| 图鉴名称 | `LineEdit`，失焦/回车写回清单 |
| 数值模板（stats） | 表格六列：名称 / id（只读）/ 类型（int·float）/ 默认 / 最小 / 最大；`min ≤ max` 互相钳制；打开时自动去重历史重复 id |
| 实例分布 | 按地图分组列出该类型全部实例：`id` + 各数值就地可改 |
| 删除此资产 | 先扫全项目引用（哪些地图、多少个实例），有引用需二次确认 |

**实例分布的数据来源**：当前打开的地图**只读画布内存**（新增未保存的会出现、已删除的不残留），
其余地图读磁盘。改某个实例的数值 = 写该实例 `props.stats` 覆盖（不是改类型模板）；
当前地图走画布（进撤销栈、标脏），其余地图直接落盘。三层合并算法
（实例 > 定义 > 清单默认）与游戏运行时一致（`def_model.gd`）。
列表为空（含刚删掉最后一个资产）时右栏整体走空态，不留上一项的陈旧控件。

清单写回：剥内部键（`_` 开头、`tiles[].atlas_abs`、内置种类）后 JSON 校验再写盘。

### 9.2 交互约定

- **左键 = 放置/涂刷，右键 = 擦除/删除**，语义由层下拉决定，没有工具要选。
- **框选开关**在状态栏右侧（不是快捷键）；打开后左键拖动 = 框选，关闭回到涂刷/放置，
  此时 `Ctrl+拖动` 仍可作为框选入口。
- 网格开关也在状态栏右侧；未保存徽章、光标坐标、当前层与笔刷信息常驻状态栏右侧。
- `Alt+左键` = 吸管，取光标格瓦片（任何层可用）；实体层取实体类型。
- 未打开地图时禁用全部编辑交互。

### 9.3 界面结构

```
┌ 顶栏：项目名 │ 设置▾ │ ───── │ 地图▾  [关卡][内容][资产] │ ─ │ 试玩配置 · ▶试玩 ┐
├──────────────┬──────────────────────────────────────────────────────────────┤
│ 左栏 200px   │ 画布（SubViewport，吃满剩余宽高）                            │
│ 层：… ▾      │                                                              │
│ ─────────    │  ┌ 选中信息条（浮在画布下沿，仅选中时显示）┐                 │
│ 资产列表     │                                                              │
│ （按层切换） │                                                              │
├──────────────┴──────────────────────────────────────────────────────────────┤
│ 状态栏：操作消息（左，撑满） │ 框选 · 网格 · 层/笔刷 · 光标坐标 · 未保存 · ? │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 画布上方**没有横带**；编辑工具与剪贴板按钮一概不在顶栏。
- 左栏只决定「给画布喂什么」：层下拉 + 资产列表。
- **内容 / 资产面板**共用 `project_shell` 外壳：顶栏（标题 + 项目徽章 + 同一套 `TopBarNav` + 保存）
  + 内容区 + 状态栏；`Esc` 回画布，`Ctrl+S` 按当前视图分派保存目标。
- **弹窗**统一走 `_popup_body` / `_open_popup`：按内容最小尺寸居中并夹回可视区；
  内容宽度固定 `POPUP_BODY_W = 340`，换行标签必须显式给宽度（否则 Label 宽度被测成接近 0、
  高度爆成几十行，把弹窗撑到一屏）。
- **空状态**：未开图时画布中央给引导；资产列表/内容列表为空时都是图标 + 主文案 + 下一步提示。

### 9.4 撤销与缓存

- 撤销栈上限 80 步，快照是整图 JSON 字符串（比嵌套字典省内存，深拷贝天然隔离）。
- 撤销恢复走 `load_data(keep_dirty=true)`，图层锁定状态保留。
- 派生缓存与失效点：

| 缓存 | 键 / 触发 | 失效方式 |
|---|---|---|
| 实体 `by_id` 索引 | 画布实体集 | `_mark(ents_changed)`；只改瓦片/碰撞时传 `false` 避免无谓失效 |
| 实体引用集 | `MapStore.project_rev` | 任何 `write_text` 成功即 `rev+1`；换图时显式 `invalidate_ref_cache()` |
| 实体缩略图 | 清单目录 + `project_rev` | 随 rev 变化重建 |
| TileSet / 图集纹理 | 图集路径 + `tileSize` + 各图集 mtime | 外部改图集后自动重建 |
| 地图读缓存 | 文件 mtime | 写盘时 `_cache.erase(path)` |

## 10. 校验

两套静态校验，都是「issue 列表」形状 `{severity, path, message}`：

### 10.1 清单校验（`manifest_validation.gd`，读清单时执行）

| 检查项 | 级别 |
|---|---|
| `tiles` / `layers` / `entities` 不是数组 | 错误 |
| `tileSize` 非正数 | 错误 |
| 图集 `id` 为空或重复 / `atlas` 为空 / 路径含 `..` | 错误 |
| `palette[]` 条目不是对象 / `cell` 少于两项 | 错误 |
| 图层 `id` 为空或重复 / 不是 `terrain`·`decor`·`collision` | 错误 |
| 缺推荐图层（terrain/decor/collision） | 警告 |
| 实体 `id` 为空或重复 / `fields`·`stats` 非数组 / 字段 id 空或重复 | 错误 |

有错误时清单整体作废，进项目错误页；只有警告时正常进入，警告挂在清单 `_warnings`。

### 10.2 地图数据校验（`map_data_validation.gd`，打开/保存/导出时执行）

| 检查项 | 级别 |
|---|---|
| `terrain` / `decor` / `collision` / `spawn` 结构不是数值对 | 错误 |
| 实体不是对象 / `id` 重复 / `x`·`y` 非数值 | 错误 |
| 实体 `scene` 为空 | 错误 |
| 实体 `scene` 不在当前清单 | 警告 |
| 实体 `props` 不是对象 | 错误 |
| `functions` 不是数组 / 条目不是对象 / `fn` 为空 | 错误 |
| `functions[].fn` 未在清单声明 | 警告（允许先放数据后补实现） |
| `functions[].content`·`name` 非字符串 / `order` 非数值 / `parallel` 非布尔 | 错误 |

有错误则该图拒收（`decode_text` 返回空数据 + 问题列表），不把坏数据交给画布。

> **已删除**：`map_validate.gd`（跨图引用完整性 / portal 配对 / exit 死链 / 改名引用迁移）、
> `level_list.gd`（关卡清单与世界拓扑）、`content_validate.gd`（跨资源总校验）。
> 传送配对、跨图选点、世界拓扑、关卡清单都已从产品中移除。

## 12. 已知边界

- 地图改名不迁移任何引用（`target_map` 之类跨图引用需手工改），旧版本曾做过迁移，现已按拍板取消。
- 自动草稿整图覆盖写、不做多版本；草稿不会自动载入，需手动打开（放弃修改时弹窗会打印路径）。
  正式保存另有 `maps/.history/*.1..3` 三轮备份。
- 撤销快照是整图快照，大图（数千格 + 数百实体）连续操作仍有内存与耗时成本。
- 校验只做静态数据检查，不验证运行时可达性（例如落点是否在实心碰撞里）。
- 试玩进程跟踪基于 Windows `tasklist` 轮询；其它平台视为一直在运行。
- `trigger_zone` 的尺寸/触发方式/绑定事件目前**没有专用编辑控件**，只能直接改地图 JSON。
- 不做瓦片自动拼接（autotile）；碰撞自动生成是辅助功能，生成后仍可手改。
- 无图集编辑器入口；新增瓦片组需要直接改清单。
- 编辑器写盘只有一条路径：`editor_canvas.extract()`；游戏侧 `MapLoader` 只读，不反向写回，避免格式分叉。
- 内容系统只做「绑定 + 内容字段编辑」，功能行为完全在项目侧；编辑器不校验内容语义。
