# Market Hand

这个独立接入样例负责发牌、计算分数、胜负判定、显示结算和重开。游戏只读编辑器发布的清单、卡牌、牌组和结算文案，不引用编辑器源码。

从编辑器工程根目录运行单项作者验收：

```powershell
godot --path . --rendering-method gl_compatibility --audio-driver Dummy --script res://tests/run_card_authoring.gd
```

验收只预装游戏代码和字段声明，通过项目内容库建立两张卡牌、两条结算和一份遭遇，重载后从「试玩所选内容」启动独立游戏。游戏以正常交互的按钮逻辑分别打出两张卡牌，再用加载回执返回得分和结算。验证模式只自动点击按钮；删除临时项目清单中试玩参数末尾的 `--verify` 并移除 `--headless`，即可从编辑器启动可交互版本。此样例从编辑器传入的项目内容入口启动。

这验证声明式记录、跨内容引用及独立试玩能承载卡牌流程，不表示编辑器内置发牌、战斗或卡牌规则。
