# Signal Room：独立屏幕游戏接入样例

这是独立屏幕解谜样例，支持纯屏幕流程，也可从屏幕直接进入地图。此目录的 Godot 工程不引用编辑器源码。
综合验收脚本把它复制到临时项目，只准备两个字段、一种画幅和启动声明；
其余内容都通过编辑器界面制作。

- `signal` 内容的 `PANE` 字段保存参考视图 ID，`TEXT` 字段提供结尾文字。
- 游戏用自己的 Godot 控件和 `signal/relay` 样式渲染屏幕。同一渲染函数处理游戏界面和编辑器发来的布局快照。
- 按钮读取作者设置的 `{function, content}`，切换到下一个内容。编辑器不解释按钮后的行为。
- 作者从内容库发起无地图试玩。验收模式通过按钮的正常输入路径触发切换，并报告实际打开的内容、屏幕和结尾文字。

在编辑器根目录运行 `tests/run_author_workflow.gd` 可重跑本例。


可单独运行 `godot --path . --script res://tests/run_screen_navigation_authoring.gd`，
验证作者配置正式首页、设置屏幕和教学入口，再经地图到结果及结算。设置模块的默认音量、字幕开关和 Apply 出口由编辑器保存，
游戏用滑杆与开关接受玩家值，应用到混音和字幕，重启后从玩家配置读回。
图组事件层只绑定到作者选中的地图，另有独立绘制文档；编辑器验证范围，游戏验证该图的绘制实体和事件目标。
独立游戏回执报告实际地图码、实例码、屏幕顺序、设置和结算，不引用编辑器脚本完成运行时行为。
