# Signal Room：独立屏幕游戏接入样例

这是无地图的屏幕解谜流程。此目录的 Godot 工程不引用编辑器源码。
综合验收脚本把它复制到临时项目，只准备两个字段、一种画幅和启动声明；
其余内容都通过编辑器界面制作。

- `signal` 内容的 `PANE` 字段保存参考视图 ID，`TEXT` 字段提供结尾文字。
- 游戏用自己的 Godot 控件和 `signal/relay` 样式渲染屏幕。同一渲染函数处理游戏界面和编辑器发来的布局快照。
- 按钮读取作者设置的 `{function, content}`，切换到下一个内容。编辑器不解释按钮后的行为。
- 作者从内容库发起无地图试玩。验收模式通过按钮的正常输入路径触发切换，并报告实际打开的内容、屏幕和结尾文字。

在编辑器根目录运行 `tests/run_author_workflow.gd` 可重跑本例。
